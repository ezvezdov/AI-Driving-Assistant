# 🤖🚗 AI Driving Assistant
A Retrieval-Augmented Generation (RAG) chatbot for answering country-specific driving regulation questions using provided documents as the knowledge source.


## ⚙️ Installation

```bash
git clone ...
cd RAG
python3 -m venv .venv
source .venv/bin/activate
pip install .
```

## Usage
```bash
python3 main.py
```
